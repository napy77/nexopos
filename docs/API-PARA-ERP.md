# API para el sistema del comercio

**La documentación vive en la aplicación, no acá:**

- Publicada: <https://nexopos.app/docs/api>
- Fuente: `frontend/app/docs/api/doc.tsx`

Está ahí y no en este archivo por una razón concreta: **el que la lee es un
desarrollador de la empresa que hace el ERP**, y no tiene cuenta en el POS ni
acceso a este repositorio. Un markdown acá le sirve a nosotros y a nadie más.

Se lee sin iniciar sesión, y el comerciante tiene el link en Configuración →
Conectar tu sistema, al lado de donde genera la clave.

Este archivo queda como puntero para que nadie escriba la documentación dos
veces: si están en dos lados, en algún momento dicen cosas distintas.
